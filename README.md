# 🐱 MeowGPT

A simple chatbot that only speaks in **meows**.

## 🌐 Try it

**Website:** https://meow.auguxt.dev

**API:** https://meowgpt-api.onrender.com

## 💬 How it works

You type something:

```text
Hello bro

MeowGPT replies:

meow meow meow 🐱

Short message = fewer meows.

Long message = more meows.

exit

Clone the project:

git clone https://github.com/auguxt/meowgpt.git
cd meowgpt

Install:

pip install -r requirements.txt

Start:

uvicorn main:app --reload

Then open:

http://127.0.0.1:8000
